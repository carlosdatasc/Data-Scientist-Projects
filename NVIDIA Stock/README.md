# NVIDIA Valuation Engine: Automated DCF Model

## Executive Summary

**Is there an Artificial Intelligence bubble?**
This project stems from the need to determine the "real" intrinsic value of **NVIDIA (NVDA)** amidst current market speculation. Rather than relying on subjective opinions, this engine automates financial calculation based on fundamental data.

**Objective:**
To develop a Python tool that replaces static spreadsheets, enabling a dynamic **Discounted Cash Flow (DCF)** analysis. The script extracts real-time data, projects growth scenarios, and mathematically compares the calculated value against the market price to validate or refute the hypothesis of overvaluation.

## Key Features

This is not just a calculation script; it is a financial data workflow (ETL):

- ** Live Data Ingestion:** Automatic connection to the Yahoo Finance API (`yfinance`) to extract the Balance Sheet, Cash Flow, and current price without manual intervention.
- ** Automatic WACC Calculation:** Estimation of the Weighted Average Cost of Capital (discount rate) based on the company's current debt/equity structure.
- ** Adjustable Exponential Projection:** Two-stage modeling: hyper-growth phase (Short Term) vs. maturity to perpetuity (Long Term).
- ** Result Visualization:** Automatic generation of comparative charts (Intrinsic Value vs. Market Price) to facilitate decision-making.
- ** Sensitivity Analysis:** Capability to adjust risk rates to perform *Stress Testing* on the stock.

## Tech Stack

- **Python:** Core logic and financial algorithms.
- **Pandas:** Structured manipulation of financial DataFrames.
- **yFinance:** Real-time stock market data extraction.
- **Matplotlib:** Data visualization and chart generation.

##  Financial Logic (Methodology)

For this analysis, a **conservative approach** (Value Investing) has been adopted to stress-test the solidity of the investment:

1. **Model Used:** Discounted Free Cash Flow (DCF - 2 Stages).
2. **Discount Rate (WACC):** **16%**. (The stock is penalized with a high rate due to historical volatility and sector risk).
3. **Projected Growth (Years 1-5):** **35%** annually. (Prudent estimate compared to the recent ~96% historical average, assuming natural deceleration).
4. **Terminal Value (Perpetuity):** **3%**. (Aligned with average global GDP growth).
